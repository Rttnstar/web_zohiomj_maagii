# Криптографын үндэс — Лаборатори 5: S-DES

## Агуулга

`sdes_lab5.py` нь дараахыг хэрэгжүүлсэн:

- 10-bit түлхүүрээс `K1`, `K2` үүсгэх;
- стандарт S-DES хүснэгтүүдээр 8-bit блок шифрлэх/тайлах;
- UTF-8 кирилл текстийг byte түвшинд файл шифрлэх;
- файл тайлсны дараа padding-ийг автоматаар арилгах.

## Ажиллуулах

```bash
python3 sdes_lab5.py keys 1010000010
python3 sdes_lab5.py block encrypt 01000011 1010000010
python3 sdes_lab5.py block decrypt 11000110 1010000010
python3 sdes_lab5.py file encrypt plaintext_mn.txt ciphertext.sdes 1010000010
python3 sdes_lab5.py file decrypt ciphertext.sdes decrypted_mn.txt 1010000010
```

`1010000010` түлхүүрээр стандарт тооцоход `K1=10100100`, `K2=01000011` гарна.

## Алгоритмын тайлбар

1. 10-bit түлхүүрийг P10-оор сэлгэж, 5+5 болгон хуваана.
2. Хоёр хэсэгт зүүн circular shift хийж P8-оор сэлгэхэд K1 гарна.
3. Тэр хэсгүүдийг дахин нийт 3 байр (эхний 1 + нэмэлт 2) зүүн shift хийж P8-оор сэлгэхэд K2 гарна.
4. 8-bit өгөгдөлд IP, дараа нь `fk(K1)`, swap, `fk(K2)`, IP⁻¹ дарааллаар ажиллана.
5. `fk` дотор баруун талыг EP-ээр 8-bit болгож түлхүүртэй XOR хийнэ. Дараа нь S0/S1, P4, зүүн талтай XOR хийнэ.
6. Тайлахдаа яг ижил алгоритмыг K2, K1 гэсэн урвуу дарааллаар хэрэглэнэ.

S-DES нь 8-bit блок ашигладаг тул файл дээрх byte бүрийг тусад нь боловсруулсан. Файлын урт 8-д хуваагдахгүй үед төгсгөлд 1–8 ширхэг padding byte нэмдэг.

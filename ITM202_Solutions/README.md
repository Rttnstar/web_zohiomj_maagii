# ITM202 лабораторийн ажлууд

Эдгээр нь beginner түвшний жишээ шийдлүүд. Файлыг browser дээр нээж шалгана.

## Яаж ажиллуулах вэ?

1. Доорх `lab1`, `lab2`, `lab3`, `lab4` хавтасны аль нэгийг нээнэ.
2. `index.html` файлыг double-click хийнэ.
3. Нэр, оюутны код, зураг зэрэг `TODO` гэсэн хэсгүүдийг өөрийн мэдээллээр солино.

## Лаборатори бүрийн санаа

- **Lab 1:** 2 HTML хуудас хийж, `a` холбоосоор хооронд нь шилжинэ.
- **Lab 2:** 3 хүснэгт хийнэ: CV, хичээл сонголт, хуваарь.
- **Lab 3:** `form` ашиглан мэдээлэл авна. Submit дарахад амжилтын хуудас нээгдэнэ. Мөн iframe-ээр хэсгүүдийг харуулна.
- **Lab 4:** audio, video, canvas, SVG ашиглана. Өөрийн `my-audio.mp3`, `my-video.mp4` файлуудаа `media` хавтаст байрлуулна.
